🔧 JioFiber + Downstream Router Setup Topology

Because JioFiber home routers (192.168.29.1) run locked firmware without custom DNS fields, connect an OpenWrt-native travel router (e.g. GL.iNet GL-MT3000 Beryl AX) downstream in Router Mode (`192.168.30.1`).

Network Architecture Diagram

Internet ──> JioFiber Router (192.168.29.1, untouched)
                  │ (LAN port -> WAN port)
                  ▼
            OpenWrt Router (192.168.30.1, double-NAT)
                  │
                  ├──> AdGuard Home + Unbound (192.168.30.2)
                  └──> Smart TVs (Samsung, LG, Roku, Fire TV)

Layer 2 Encrypted-DNS Bypass Prevention Commands (OpenWrt SSH)

# 1. Force outbound port 53 DNS to AdGuard Home
uci add firewall redirect
uci set firewall.@redirect[-1].name='Force-AdGuard-DNS'
uci set firewall.@redirect[-1].src='lan'
uci set firewall.@redirect[-1].src_dport='53'
uci set firewall.@redirect[-1].dest_ip='192.168.30.2'
uci set firewall.@redirect[-1].dest_port='53'
uci set firewall.@redirect[-1].proto='udp'
uci set firewall.@redirect[-1].target='DNAT'

# 2. Block outbound DoT (853) & DoH (443 to Google/Cloudflare IPs)
uci add firewall rule
uci set firewall.@rule[-1].name='Block-DoT-Port853'
uci set firewall.@rule[-1].src='lan'
uci set firewall.@rule[-1].dest='wan'
uci set firewall.@rule[-1].dest_port='853'
uci set firewall.@rule[-1].proto='tcp udp'
uci set firewall.@rule[-1].target='DROP'

uci commit firewall
/etc/init.d/firewall restart
